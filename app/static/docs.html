POST /api/generate
Primary Artwork Synthesis Engine

Dispatches natural language prompts to selected generative AI providers (Pollinations Flux, Sana, Turbo, OpenAI DALL-E 3, Stability SDXL, or Mock Engine). Enforces strict aspect ratio pixel dimensions, verifies decoded binary stream via Pillow Image.open().load(), and executes exponential backoff auto-retry upon corrupted streams.

Request Body (JSON)

Field Type Required Description
prompt string Yes Natural language prompt describing the artwork (3 to 1000 characters).
aspect_ratio enum No (default: 1:1) Target aspect ratio: "16:9" (1920×1080), "1:1" (1080×1080), "9:16" (1080×1920).
provider string No (default: pollinations_flux) Target AI engine: pollinations_flux, pollinations_sana, pollinations_turbo, openai, stability, mock.
enable_ai_enhancer boolean No (default: true) Activates semantic prompt reasoning for high-detail 1080p generation.
api_key string Optional User API key for paid models (OpenAI DALL-E 3 or Stability AI SDXL). Free models require no key.
style enum No (default: cinematic) Style aesthetic preset: cinematic, photorealistic, cyberpunk, anime, digital_art, vivid, watercolor.
count integer No (default: 1) Batch quantity of artworks to generate (1 to 4).
negative_prompt string Optional Cues to avoid in generation (e.g. blurry, watermark, artifacts).
simulate_corruption boolean No (default: false) Simulate 1 severed data stream to demonstrate Pillow scanline detection and auto-retry.

GET /api/history
Verified Artwork Artifact Catalog

Retrieves all successfully synthesized, Pillow scanline-verified artwork assets persisted on disk in outputs/ with metadata including width, height, aspect ratio, style, timestamp, and byte size.

GET /api/health
Pipeline Health & Supported Models

Returns server readiness status, active AI provider engine, complete list of supported free and paid AI models, maximum retry limit, and output directory state.

POST /api/prompt/optimize
Semantic Prompt Intelligence Engine

Analyzes user prompts with domain-aware semantic heuristics (automotive, character, gaming, space, nature) and expands them with volumetric lighting, optical camera specifications, and negative prompt guardrails for maximum 1080p generation quality.

DELETE /api/history/{identifier}
Permanent Artifact Removal

Permanently removes an image artifact (.png) and its metadata companion (.json) from the server's outputs/ archive directory.

GET /api/outputs/{filename}
Secure Binary Asset Delivery

Serves verified PNG binary image artifacts with path-traversal attack protection. Returns HTTP 403 on illegal traversal attempts, and HTTP 404 if the asset does not exist.

Pillow Stream Integrity Gate Architecture

Network transmission interrupts, proxy truncations, or incomplete HTTP chunk streams can corrupt image payloads without throwing standard network-level errors. To guarantee zero damaged assets, the pipeline executes a mandatory scanline decoding gate:

1 Binary Payload Stream Raw bytes received from AI provider
→
2 Pillow Image.open().load() Forces decompression of all scanlines
→
3 BrokenDataStream Catch Catches OSError / TruncatedData
→
4 Auto-Retry (Exp. Backoff) Purges bad asset & retries (up to 3x)
